# 화면을 만들다 추가로 필요해진 API

기존 명세에 없는 것만 적는다. 디자인을 굳히는 중이라 더 늘 수 있다.
**확정 전까지는 요청이 아니라 예고다.**

작성 2026-10-30

---

## 1. 작물 목록

```
GET /crops?q=배
→ [{ id: "...", name: "배추" }, { id: "...", name: "배" }]
```

밭을 등록할 때 구역마다 작물을 고른다. 지금은 `mock.ts`의 `CROPS` 상수를 쓴다.
명세에 `crop_id`를 받는 자리는 있는데 **그 id를 어디서 얻는지가 없다.**

쓰는 곳: `src/components/CropField.tsx`

---

## 2. 창고 (내가 가진 약)

```
POST   /inventory        { drug_id }
DELETE /inventory/{drug_id}
GET    /inventory        → [drug_id, ...]
```

판정이 「가능」이어도 그 약이 없으면 오늘 못 뿌린다. 창고에 있으면 바로 뿌린다.
그래서 첫 화면에서 같은 판정끼리는 창고에 있는 약을 먼저 보여준다.

지금은 `mock.ts`의 `INVENTORY` 상수에 6개가 박혀 있고,
넣고 빼는 건 `AppState.toggleInventory`가 메모리에서만 처리한다.

쓰는 곳: `src/screens/Verdict.tsx` (넣기 버튼), `MapHome` · `DrugList` (배지와 정렬)

---

## 참고 — 이미 명세에 있다고 보고 쓰는 것

아래는 새로 요청하는 게 아니라, 화면이 이 모양으로 쓴다는 메모다.

| 쓰는 곳 | 필요한 값 |
| --- | --- |
| 판정 | 약 × 작물 × 병해충별 등록 정보 (수확 전 일수, 최대 횟수, 희석배수, 계통) |
| ③횟수 | 그 구역 이번 농사 살포 기록. 취소한 것 제외 |
| ④계통 | 직전 살포 약의 계통 번호 |
| 통계 | 읍면별 계통 사용 비중 (`REGION_STATS` 모양) |
| 봉지 찍기 | OCR 결과에서 약 이름 매칭 |
