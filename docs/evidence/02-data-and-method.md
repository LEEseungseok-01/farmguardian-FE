### 방법론 — 네 가지 체크

| 체크 | 성격 | 틀리면 |
| --- | --- | --- |
| ① 등록 | 법 | 출하 차단 |
| ② 시기 (수확 전 일수) | 법 | 출하 차단 |
| ③ 횟수 (최대 횟수) | 법 | 출하 차단 |
| ④ 계통 | 효과 | 약이 안 듣는다 |

①②③ 중 하나라도 걸리면 **불가**, ④만 걸리면 **주의**.
종합 우선순위: `RED > NA > UNKNOWN > AMBER > GREEN`

→ 계약: `docs/technical/api-spec.md` 11절 (하드 룰)
→ 흐름도: `docs/diagrams/02_판정_흐름.mmd`

### 데이터가 비어 있을 때 — 세 갈래로 나눴다

실데이터 3,870줄을 세어서 나눴다. **추측하지 않는다.**

| 구분 | 줄 | 처리 |
| --- | --- | --- |
| `ok` | 3,303 | 날짜·횟수 계산 |
| `stage` | 519 | 심을 때 쓰는 약 → ② **NA** (항목 자체가 없음) |
| `plant_rel` | 4 | 「파종(정식)일부터14일」 → 정식일 + 14일 계산 |
| `no_std` | 41 | 기준 미표기 → ②③ **확인 필요** |
| `failed` | 3 | 사람이 봐야 함 |

**추측이 불가능하다는 근거까지 확인했다.** `no_std` 41줄은 같은 품목명이 3,870줄 어디에도 수확 전 일수가 없다(0건).
`stage` 519줄 중 83줄은 같은 약인데 값이 갈린다. 한 약 안에서도 대상 해충에 따라 「정식기」와 「수확 7일전」이 둘 다 나온다.

→ 근거 전문: `docs/internal/팜가디언_제품쟁점.md` 11번

### 사진을 어디에 쓰고 어디에 안 쓰는지

**작물 사진으로 병을 알아내지 않는다.** 검토 후 제외했다.

| 확인한 것 | 결과 |
| --- | --- |
| AI Hub 작물 질병 데이터셋 | 작물 10종. **감자가 없다** |
| 해외 공개 데이터셋 | 연구실 환경에서 잎을 떼어 단독 촬영한 사진으로 구성 |

강원 고랭지감자 점유율이 99.8%인데 학습 자료에 감자가 없다. 해외 자료는 촬영 조건이 밭과 달라 그대로 쓸 수 없다.
→ 범위 제외 명시: `docs/shared/팜가디언_PRD.md` 99줄

대신 병해충은 사용자가 증상 부위를 고른 뒤 도감 후보에서 직접 선택한다. 확률이나 추천 순위를 제시하지 않는다.

**사진은 약 포장지에 쓴다.** 약제를 식별하는 용도다 (FR-602).

| | |
| --- | --- |
| 모델 | `claude-haiku-5-5` |
| 하는 일 | 포장지 글자를 읽어 상표명·품목명·회사명 후보를 반환 |
| 안 하는 일 | 제품 확정. 약 목록을 모델에 주지 않는다 |
| 제품 확정 | `pesticide` 표 1,294개와 `pg_trgm` 유사도 대조 |
| 비용 | 사진 1장 약 0.4원 (입력 $0.10 / 출력 $0.50 per MTok) |

**왜 일반 OCR이 아니라 이 방식인가.** 등록약 4,133줄의 상표명을 세어 보면 이유가 나온다.

| 상표명 길이 | 개수 |
| --- | --- |
| 2글자 | 140 |
| 3글자 | 719 |
| 4글자 | 263 |
| 5글자 이상 | 172 |

고유 상표명 1,294개 중 **859개(66%)가 두세 글자**다(지존, 섬광, 대포, 귀품, 옵션). 영문만으로 된 상표명은 0개다.

포장지에는 상표명·품목명·성분·함량·등록번호·회사명·적용 작물표·안전사용기준·주의사항이 함께 인쇄된다. 일반 OCR은 이 글자를 좌표와 함께 전부 반환하므로, 그중 어느 두세 글자가 상표명인지 판별하는 규칙을 따로 구현해야 한다. 상표명이 두세 글자인 비율이 66%여서 길이·위치 규칙으로 분리되지 않는다.

**사용자 확인을 필수로 둔 근거.** 이름이 비슷한 상표 18쌍을 계열 코드와 대조했다.

| 상표명 | 계열 코드 |
| --- | --- |
| 보스 | 4a |
| 보스카 | **29** |
| 카브리오 | 다3 |
| 카브리오팀 | **아5+다3** |
| 젠토스타 | 4a |
| 젠토스타일 | **사1** |

한 글자 차이로 계통이 달라진다. 오인식 결과를 그대로 판정에 넣으면 ④계통 집계가 어긋난다. 따라서 인식 결과는 후보 목록으로만 제시하고, 사용자가 제품을 고른 뒤에 판정한다.
→ 수락 기준: `docs/shared/팜가디언_요구사항명세서.md` FR-602
→ 구현: `docs/technical/팜가디언_테크스펙.md` 5.6

**후속 검토.** PSIS에 농약 바코드 검색(`psis.rda.go.kr/psis/pma/agc/res/agchmBrcdSrchLst.ps`, 로그인 필요)이 있다. 바코드는 품목이 확정되므로 유사 상표명 혼동이 없다. 포장이 손상되거나 소분된 약에는 쓸 수 없어 OCR을 대체하지 않고 보완 경로로 검토한다.

### 구현·시연 수준

- 프로토타입: 화면 12개가 실제로 동작. 판정 엔진이 코드로 들어 있다
- 검증 사례 8건이 기대값대로 나온다 (가능 / 주의 / 불가 / 확인 필요 / 심을 때 전부 포함)
- 자동 테스트: 렌더 2,650건 실패 0, 클릭 8,991회 실패 0
- 접근성·일관성 린트 통과 (대비 4.5:1, 글꼴 굵기 3종)
