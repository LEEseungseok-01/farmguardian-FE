### 시연 영상

운영 계획 원문: 「장비 시연을 진행하는 팀의 경우 현장에서의 미작동 등을 고려하여
시연 영상을 촬영, 발표자료와 함께 제출」

우리는 시연한다. 촬영 대상은 **밭이 아니라 화면**이다.
프로토타입을 모바일 폭으로 띄우고 시나리오 하나를 끝까지 녹화한다. 3~4분.

```
구역 고르기 → 병해충 찾기 → 약 고르기 → 네 가지 체크
→ 번호 눌러 근거 원문 보기 → 기록하기
```

현장에서 라이브 시연 대신 이 영상을 틀어도 된다.
