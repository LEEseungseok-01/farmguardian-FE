## 우리 근거

### 관점 1 — 빈칸을 통과로 넘기지 않는다

보통은 데이터가 비면 조용히 넘긴다. 우리는 **비었다는 사실 자체를 화면에 띄운다.**

```
확인 필요 (UNKNOWN)    값이 없어서 확인을 못 했다
심을 때   (PREPLANT)   아직 따질 때가 오지 않았다
```

둘을 따로 둔 게 핵심이다. **「모름」과 「아직 따질 때가 아님」은 다르다.**
아직 심지 않은 밭은 수확일이 없다. 「수확까지 며칠」을 계산할 대상 자체가 없다.
이걸 「모름」으로 묶으면 농가는 「자료가 부실하구나」로 읽고, 「통과」로 묶으면
심지도 않은 밭에 약을 뿌리게 된다.

판정 상태가 보통 3개(가능·주의·불가)인데 우리는 **5개**다.
→ `docs/internal/팜가디언_제품쟁점.md` 11번

### 관점 2 — 법 문제와 효과 문제를 색으로 갈라놨다

| | 걸리면 | 색 |
| --- | --- | --- |
| ①등록 ②시기 ③횟수 | 출하가 막힌다 | 불가 (빨강) |
| ④계통 | 약이 덜 듣는다 | 주의 (노랑) |

같은 「문제」지만 **결과의 무게가 다르다.** 농가가 급할 때 ④만 걸렸으면 뿌려도 된다.
이걸 한 덩어리로 묶으면 농가는 전부 무시하게 된다.

### 관점 3 — 저항성을 「지역 단위」로 봤다

개별 농가는 자기 밭만 본다. 저항성은 지역 단위로 퍼진다.
옆 밭이 전부 같은 계통을 쓰면 혼자 바꿔도 이미 저항성을 가진 벌레가 넘어온다.

그래서 면 단위로 계통 사용 비중을 모아 보는 화면을 설계했다 (FR-503, P2).
개인 화면에서는 보이지 않는 층이다.

### 관점 4 — 판정만 내놓지 않고 근거 원문을 같이 보여준다

「불가」라고만 하면 농가는 안 믿는다. 번호를 누르면 **PSIS 원문 그대로**가 나온다.
「수확7일전」「3회」「정식기」 같은 원문이다. 우리가 요약한 말이 아니다.

### 기존 서비스와 무엇이 다른가

| | 등록 기준 조회 | 내 살포 기록 | **둘을 대조해 판정** | 계통(저항성) | 쓰기 전 조건 |
| --- | --- | --- | --- | --- | --- |
| **팜가디언** | O | O | **O** | **O** | 가입 없이 바로 |
| PSIS 농약정보서비스 | O | X | X | 계통 표기만 | 없음 |
| 제주다 | O | 방제이력 조회 | X | X | 경영체 등록 + 필지 인증 |
| GAP 영농일지 | O | O | X | X | 인증 심사용 |
| NH오늘농사 | O | O | X | X | 농협 거래 기준 |
| 팜식스플러스 | X | O | X | X | 없음 |

**조회 앱은 기준만 보여주고, 기록 앱은 기록만 쌓는다.**
둘을 대조해서 「이 약을 지금 이 구역에 쓸 수 있는지」 답하는 서비스가 없다.
③횟수와 ④계통은 기록 없이는 계산 자체가 안 되는데, 기록을 가진 앱은 판정을 안 한다.

④계통을 보는 곳도 우리뿐이다. 다른 앱은 법적 기준(①②③)까지만 본다.
저항성은 법 위반이 아니라서 아무도 막지 않는다. 그런데 평창에서 이미 약이 안 듣는다.
