# farmguardian-FE

팜가디언 프론트엔드 레포. 기획·데이터·기술 문서도 여기 모여 있습니다.

## 어디를 보면 되는지

| 경로 | 내용 |
|---|---|
| `prototype/farmguardian-v2.html` | **동작하는 프로토타입.** 브라우저로 열면 됩니다. FE 구현 기준 |
| `docs/shared/` | PRD · 요구사항명세서 · 페르소나 |
| `docs/technical/` | API 명세 · DB 시드 전달서 · 테크스펙 |
| `docs/diagrams/` | 사용자 흐름 · 판정 흐름 · 기능 구조 · 데이터 관계 (Mermaid) |
| `docs/evidence/` | 심사 기준별 근거 정리 |
| `data/파뭉-데이터수집/` | 수집 원본 엑셀 7개 + 설명 |

## 프로토타입

탭 4개입니다. **모바일** 탭이 본체고, 화면 9개가 들어 있습니다.

```
개요            서비스 설명
모바일          밭 지도 · 병해충 선택 · 매개충 · 약 목록 · 약 상세
                기록 · 논문 값 · 밭 등록 · 밭과 구역
PC 화면         같은 판정을 넓은 화면에
농업기술센터    다음 단계 기능
```

`약 상세` 화면에 4체크·근거 원문·대안이 다 들어 있습니다. 여기가 핵심입니다.

## 판정

네 가지를 봅니다.

| | 체크 | 막히면 |
|---|---|---|
| 1 | 이 작물에 등록된 약인지 | 불가 |
| 2 | 뿌려도 되는 시기인지 (수확 전 일수) | 불가 |
| 3 | 남은 횟수가 있는지 | 불가 |
| 4 | 같은 계통을 연달아 쓰는지 | 주의 |

상태 5개, 우선순위는 왼쪽이 먼저입니다.

```
불가 > 심을 때 > 확인 필요 > 주의 > 가능
RED    NA        UNKNOWN     AMBER   GREEN
```

## 스택

Vite + React + TypeScript. 상태 관리 라이브러리는 쓰지 않습니다.

판정 로직은 `src/lib/judge.ts` 한 곳에 둡니다. 프로토타입의 `judge()`를 옮긴 것으로, FE·BE가 같은 코드를 씁니다.
